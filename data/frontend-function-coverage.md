# Frontend function coverage

All functions use the existing storefront theme. No Medikabazaar theme, marketing copy, reviews, prices or branding are copied. Product facts have their own provenance.

| Area | Frontend behavior |
| --- | --- |
| Discovery | Search suggestions, keyboard selection, recent queries, category/specialty explorer, department/subcategory filters, newest additions, grid/list view, load more |
| Product | Quick view, image zoom, specifications/download, quantity, related/recent products, sharing, private notes |
| Shortlist | Persistent saved items and three-product comparison |
| Basket | Add/remove/change quantity, quick basket, undo removal, CSV/print export, bulk CSV/text list matching with explicit ambiguity review |
| Buyer | Local profile, address CRUD/default selection, checkout address prefill, local quote drafts and reordering |
| Enquiry | Validated quote form, review screen, email/WhatsApp drafts and text download |
| Accessibility | Keyboard search, modal focus handling, native dialog dismissal, responsive controls, reduced-motion back-to-top |
| Server-only boundaries | Real sign-in/OTP, payments, live stock, promotions, shipment events and placing orders remain outside this frontend-only implementation |
