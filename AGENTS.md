# Website editing instructions

- Any requested header or footer change applies to every webpage in this website, unless the user explicitly limits its scope. Update all rendered pages and their generation sources together.
- Shared header navigation is maintained in `data/header-nav.html` and consumed by `scripts/build-storefront.py`. Preserve consistent navigation and header/footer branding across existing and newly created pages.
- Preserve the original logo asset, vertical divider, and company name unless the user asks to change them.
